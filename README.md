# huntervelasquez.com

Portfolio site for Hunter Velasquez, hosted free on GitHub Pages.

- `index.html` – Home (Engineering / Photo-Video switch)
- `work/` – all projects, filters, project viewer
- `resume/` – both resumes (PDFs in `resume/`)
- `assets/data.js` – **all the words and media lists**: projects, home copy, featured items
- `assets/site.css`, `assets/*.js` – look and behaviour
- `media/img`, `media/video` – photos, posters, reels and sizzles

To change text, edit `assets/data.js` (or ask Claude). Pushing to `main` republishes in about a minute.
